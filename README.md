# lingyun · 图册

一个用代码搭出来的三维个人站。读者是招聘方，所以目标很具体：**让人一眼觉得新奇，三分钟知道我是个什么人。**

**在线地址：<https://balbonioldershaw901-a11y.github.io/lingyun/>**

## 里面有什么

| 页面 | 内容 |
| --- | --- |
| `index.html` | 首页。一张用 WebGL 搭的三维书桌，往下滚，镜头会带你看过去 |

## 技术上的几个实在处

- **纯静态**：没有后端、没有接口、没有构建步骤。这个仓库就是站点本身，克隆下来用任何静态服务器打开即可。
- **零站外请求**：字体（`assets/brush-calligraphy.ttf`）和图都在站内，没有 CDN、没有外部字体服务。
- **路径全是相对的**：所以放在 GitHub Pages 的项目子路径（`/lingyun/`）下也能正常跑；`canonical` 与 `og:*` 这类必须是绝对地址的地方由 `set-domain.cjs` 一次性写入。
- **地图是真数据**：SRTM 1 弧秒高程（NASA/USGS，公有领域，垂直基准 EGM96）。坡度、坡向、晕渲、等高线都由这份高程算出来，不是画上去的；图上凡涉及面积的数字都只出现在表格里，不叠到地图上 —— Web Mercator 在中高纬的面积失真能到两倍以上。
- **高程纹理是无损的**：terrain-RGB 把高程编进三个字节，低位字节携带 0.1 m 一级的高程，有损压缩（YUV 4:2:0）会把它碾平、让读数漂移，所以这张图只走无损编码。
